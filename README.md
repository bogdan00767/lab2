# Лабораторная работа №2: Регулярные выражения в C++

**Вариант 3: Язык разметки AsciiDoc**

## Описание проекта

Проект предназначен для проверки текста на соответствие языку разметки AsciiDoc, поиска элементов разметки (заголовки, абзацы, списки) и валидации (нормализации) пользовательских данных при заполнении анкеты с использованием регулярных выражений. Также реализована локализация интерфейса (RU/EN/DE) и генератор случайных данных.

## Задачи лабораторной работы

### 1. Проверка языка разметки

Реализовать функцию проверки текста на соответствие правилам языка разметки.

Если текст не соответствует правилам языка разметки или является другим языком разметки, необходимо вывести сообщение об ошибке в консоль приложения.

### 2. Поиск элементов в тексте

Реализовать функции поиска следующих элементов:

- **Заголовок**
- **Абзац**
- **Списки**

Для хранения найденных элементов использовать контейнеры библиотеки STL.

### 3. Проверка пользовательских данных

Реализовать функциональность проверки пользовательских данных при заполнении анкеты.

#### Поля анкеты

- Фамилия
- Имя
- Отчество
- Дата рождения
- Номер телефона
- Электронная почта

#### Функции обработки данных

1. Реализовать функцию ввода пользовательских данных.
2. Реализовать функцию проверки введённых пользовательских данных.
3. Предусмотреть различные варианты заполнения даты рождения, телефона и электронной почты.
4. Приводить введённые данные к установленному формату.

#### Пример обработки данных

**Входные данные:**

```input
Сидоров ИваН ПетРОви1ч 2002-03-01 +7996-8432-431 sidorovVV@pochta.ru
```

**Выходные данные:**

```output
Сидоров Иван Петрович 01.03.2002 +79968432431 sidorovvv@pochta.ru
```

Для проверки работоспособности функции проверки пользовательских данных необходимо реализовать генератор случайных данных.

### 4. Генерация случайных пользовательских данных

- Генерация случайного имени, фамилии, отчества.

#### Требования к генератору

- Генерация случайного имени.
- Генерация случайного отчества.
- Использование общедоступных словарей фамилий, имён и отчеств.

Генератор предназначен для автоматического создания тестовых данных, которые используются для проверки корректности работы функции валидации пользовательских данных.


## Структура проекта

- `main.cpp` — точка входа, меню и вызов заданий.
- `menu.h / menu.cpp` — реализация меню и локализация через `locales.json` (библиотека `nlohmann/json`).
- `asciidoc.h / asciidoc.cpp` — логика проверки файлов AsciiDoc и поиска элементов (чтение чанками по 8 МБ).
- `form.h / form.cpp` — валидация анкеты (ФИО, дата, телефон, email) и генератор случайных данных.
- `common.h` — вспомогательные функции (работа с UTF-8, trim).
- `data/` — словари (`surnames.txt`, `names.txt`, `patronymics.txt`) для генератора.
- `tests/` — файлы для тестирования (HTML, Markdown, пустые файлы).

## Сборка и запуск

Для сборки требуется компилятор с поддержкой C++17. Запускать программу необходимо из корневой папки проекта, чтобы пути к `locales.json` и `data/` были корректными.

```bash
# Сборка
g++ -Wall -Wextra -g3 -std=c++17 main.cpp menu.cpp asciidoc.cpp form.cpp -o output/main

# Запуск (с указанием UTF-8 локали для корректного отображения кириллицы)
LANG=ru_RU.UTF-8 ./output/main
```
